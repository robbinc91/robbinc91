# Robin Cabeza-Ruiz

**Ph.D. · Full Professor · Director, Centre for CAD/CAM Studies**  
[Universidad de Holguín](https://www.uho.edu.cu/), Cuba

I train 3D convolutional networks to segment brain MRI — cerebellum, brainstem, thalamus — so atrophy in [spinocerebellar ataxia type 2](https://en.wikipedia.org/wiki/Spinocerebellar_ataxia) can be measured instead of traced by hand.

[Portfolio](https://robbinc91.github.io) · [ORCID](https://orcid.org/0000-0003-4719-8264) · [Google Scholar](https://scholar.google.com/citations?user=MAtFl38AAAAJ) · [ResearchGate](https://www.researchgate.net/profile/Robin-Cabeza-Ruiz) · [LinkedIn](https://www.linkedin.com/in/robin-cabeza-ruiz-50575b113/) · [Email](mailto:robbinc91@gmail.com)

**2024 National Award**, Cuban Academy of Sciences (conferred 2025) — deep learning for quantifying brain-structure loss in SCA2  
**Associate Researcher**, Universidad de Ciencias Médicas de Holguín (2026)  
**Peer reviewer** for *BMC Medical Imaging*, *Neural Computing and Applications*, and *The Cerebellum*

Currently leading **early prediction of motor progression in spinocerebellar ataxias using AI**, and building the imaging tools that make those measurements reproducible.

## Research code

| Repository | What it is |
| :--- | :--- |
| **[mipaim_unet](https://github.com/robbinc91/mipaim_unet)** | U-Net with attention and inception modules for 3D brain MRI parcellation (TensorFlow / Keras) |
| **[cnn_vs_qcnn_medical_imaging](https://github.com/robbinc91/cnn_vs_qcnn_medical_imaging)** | Head-to-head of classical U-Net vs quaternion-valued CNNs for medical segmentation |
| **[cerebellar_fissures_segmentation_cnn](https://github.com/robbinc91/cerebellar_fissures_segmentation_cnn)** | Cerebellar fissure segmentation from MRI — the code behind the 2022 *Sensors* paper |
| **[neuro_code_utils](https://github.com/robbinc91/neuro_code_utils)** | Preprocessing, model conversion, and stats utilities for neuroscience deep learning |
| **[advanced-3d-mri-viewer](https://github.com/robbinc91/advanced-3d-mri-viewer)** | Desktop 3D MRI viewer with segmentation overlays (PyQt5 / VTK / NiBabel) |
| **[neuroview-html](https://github.com/robbinc91/neuroview-html)** | Browser-only 3D MRI viewer — no install, just HTML and JavaScript |

Full professor in the Faculty of Engineering at Universidad de Holguín, and director of the [Centre for CAD/CAM Studies](https://cecadcam-uho.netlify.app/). I teach programming and simulation, supervise graduate work, and review for neuroimaging and medical-imaging journals.

Open to collaborations in **medical AI**, **neuroimaging**, and **3D data analysis**.
